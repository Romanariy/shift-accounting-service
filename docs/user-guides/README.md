# Инструкции пользователей «Свод»

Материалы подготовлены 12.09.2026 по текущей версии проекта.

- `../../output/pdf/owner.pdf` — памятка владельцу, 1 страница.
- `../../output/pdf/staff.pdf` — памятка сотруднику, 1 страница.
- `../../output/pdf/admin.pdf` — руководство администратора, 37 страниц, 32 скриншота.
- `../../output/pdf/admin.html` — автономная версия руководства с оглавлением и встроенными скриншотами; открывается в браузере без сервера.

Исходные тексты: `owner.md`, `staff.md`, `admin.md`. Оригиналы снимков находятся в `screenshots/`. Скриншоты сделаны через браузер на отдельной локальной демонстрационной базе; реальная отправка Telegram не выполнялась. Имя рабочего бота и URL сайта не предоставлены, поэтому материалы ссылаются на реквизиты, выдаваемые администратором.

Готовые PDF проверены рендерингом всех страниц, оглавлением, числом иллюстраций и извлечением текста. Примеры сообщений соответствуют текущему парсеру. Руководство отмечает известные ограничения текущего интерфейса и различает статус подтверждения пакета и статус доставки.

Для повторной сборки в Windows: `.venv/Scripts/python.exe docs/user-guides/build_guides.py`. Нужен ReportLab и системный Arial; для проверки рендеринга использовался PyMuPDF. При добавлении разделов обновите таблицу страниц в начале `admin.md`.
