# Как записывать услуги в боте
Памятка сотруднику · Свод · 12.09.2026

## Перед первой записью
Получите у администратора ссылку на группу и нужную тему «Услуги». Откройте бота лично, отправьте `/start` и передайте свой Telegram ID администратору для привязки сотрудника. Рабочие записи отправляйте в настроенную группу или тему: личный чат предназначен для подключения и отчётов.

## Готовые примеры
Заменяйте дату, время, организацию и описание своими данными. «Фокус», «Рамис» и названия услуг здесь служат примерами; они должны существовать в вашем справочнике.

| Что записать | Сообщение в теме услуг |
| --- | --- |
| Смена | `12.09 10:00-14:00 Фокус` |
| Смена с комментарием | `12.09 10:00-14:00 Фокус подменил коллегу` |
| Два сопровождения | `12.09 2 сопр Фокус` |
| Уборка | `12.09 Уборка Фокус` |
| Несколько услуг за день | `12.09 10:00-14:00 Фокус + 2 сопр Фокус` |
| Разовая работа от себя | `12.09, 1500, Починил дверь, Фокус` |
| Разовая работа с исполнителем | `Рамис, 12.09, 1500, Починил дверь, Фокус` |

Расход отправляйте в отдельную тему расходов: `12.09, Краска и кисти, 1500,50, Фокус`.

## Проверьте ответ
Дождитесь «Записано:» и сверьте дату, услугу, организацию, исполнителя и сумму. При «Не удалось сохранить» запись не принята; исправьте причину. При «нужно проверить» обратитесь к администратору. Если ответа нет, сначала уточните, что выбрана нужная тема и бот работает; не отправляйте много одинаковых сообщений.

## Если ошиблись
Отредактируйте исходное сообщение и дождитесь «Записи обновлены:». Удаление сообщения в Telegram не удаляет запись из учёта: попросите администратора удалить её на сайте. Если работа уже вошла в подтверждённый счёт, исправление делает администратор с подготовкой новой версии.

## Короткие правила
- Указывайте организацию в каждой части сообщения. После `+` она не переносится из предыдущей части; без организации используется настройка самой услуги.
- Дата без года означает текущий год. Для прошлых лет пишите дату полностью. Без даты у типовой услуги или расхода используется дата сообщения по Екатеринбургу.
- Обычный `+` разделяет типовые услуги. Для плюса внутри комментария пишите `\+`. В разовых работах и расходах плюс может быть обычным.
- Сумму смены бот рассчитывает по тарифу. У почасовой услуги она может измениться после добавления часов других участников общего дня. Автоматические услуги, например телефоны, вручную не дублируйте.
